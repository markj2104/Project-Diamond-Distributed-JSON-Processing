# Project Diamond: distributed JSON processing

A coursework project by Mark Jachura connecting JSON retrieval, TLS transport, SFTP transfer, HMAC-SHA256 verification, Pyro4 remote calls, and Eve/MongoDB activity logging.

**Author:** Mark Jachura. Developed the complete project, including all four application services and the Eve/MongoDB logging components.

## Source map

| File | Responsibility |
| --- | --- |
| `App1.py` | Retrieve JSON and send it over TLS |
| `App2.py` | Receive, sign, and transfer the payload through SFTP |
| `App3.py` | Retrieve and verify the payload, compress it, and invoke App4 |
| `App4.py` | Receive a Python object over Pyro4 |
| `run.py`, `settings.py` | Eve API and MongoDB logging schema |

The source is now directly browsable. `Project Diamond.zip` is a sanitized copy of these source files, not the original environment bundle. Generated bytecode, certificates, and private keys are excluded. Original history may still contain the earlier archive.

## Setup status

This remains a multi-service coursework prototype, not a one-command production application. `requirements.txt` lists third-party imports; it is not a tested dependency lock. You need separate MongoDB and SFTP services, an appropriate local TLS certificate/key, and an isolated test environment. Do not reuse keys from old Git history.

Configure `DIAMOND_HMAC_KEY` consistently for App2 and App3, `DIAMOND_SFTP_HOST`, a trusted SSH known_hosts entry, and the paths/ports used by the services. The original SFTP path is environment-specific. `EVE_URL` and `APP4_URI` can override the logging endpoint and remote-object URI. Email recipients are empty by default; configure only authorized recipients and SMTP settings if needed.

The cleanup keeps SSH host verification enabled, moves HMAC configuration to the environment, and limits the Pyro and Eve listeners to loopback with Eve debug mode off. These are safer development defaults, not a security certification. Authentication for the API, request-size limits, timeouts, deployment configuration, and full integration testing remain further work. The paired HMAC functions are checked together for matching payloads and tampering; full workflow interoperability still needs review.

## Validation

The extracted Python files pass syntax parsing. The isolated HMAC interoperability test checks matching and modified payloads. No university infrastructure, email delivery, SFTP server, or live database was accessed during cleanup. End-to-end operation is not claimed.
